## Bug Reporting

If you've found an issue and wish to report it, the following steps will help us to diagnose the issue.

1. Search the [discussions](https://github.com/project-campground/Campground/discussions/categories/bug-reports) page. It's possible someone else is experiencing the same issue and has already reported it. You may be able to add additional context in thr comments!
2. If no discussion exists, create a new post. a form exists to help collect all of the required information.

## Feature Requests

Have an idea for a feature? We'd love to hear about it!

First, search the [ideas](https://github.com/project-campground/Campground/discussions/categories/ideas) page. It's possible someone else had a similar idea to yours. If so, jump into that conversation to show your support or make suggestions on how to improve their suggestion.

If nobody else has made a suggestion, feel free to make your own post! The form consists of several questions to help us understand what you're looking for.

After you've made your post, campers and staff will discuss and make suggestions. Once a maintainer feeels it is ready, the following steps will be performed:

1. An issue will be created in the Campground repo for the the change, linking to the discussion. It will be claimed by the staff member who is sponsoring the change.
1. If an RFC is needed, the issue will be tagged with `Status/Requires RFC`.
   1. An RFC will be created which outlines the scope of the feature and all of its requirements.
1. The issue will be tagged with `Status/Help Wanted`.
1. Child issues will be created for all of the relevant tasks or spaces, depending on the desired granularity. For instance, a feature that requires support on both the front end and back end will have subtasks created in each repo.

## Contributing Code

The best way to get started with contributing code is to look in the issues tab for issues that are tagged with [help wanted](https://github.com/project-campground/Campground/issues?q=is%3Aissue+state%3Aopen+label%3A%22Status%2FHelp+Wanted%22).

If you find an issue you are wanting to contribute to, comment in the issue that you would like to be assigned and how you would like to contribute. A staff member will assign you to one or more of the child issues so that you can begin contributing.

Contributing follows the standard source control flow:

1. Fork the repo you are contributing to.
1. Create a new branch. We recommend including the issue number in the branch, like `AddMarshmallowRoasting-1234`, but you are welcome to name your branch whatever you like.
1. Create a draft pull request with a name that describes the feature and specify in the body that it closes the original issue. You can use this PR to ask questions and give status reports.
1. When your PR is ready for review, take the PR out of draft status.
1. A member of staff will review your contribution and advise changes.
1. The change will be merged.

## Other Questions

If you've run into a configurtion issue when self hosting or just want to know how something works, feel free to open a discussion or ask us about it in the official Discord server or Campsite!
